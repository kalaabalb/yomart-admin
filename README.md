

## Staging catalogue for visual review

The connected `yomart_staging` database currently contains 4 categories, 4 subcategories, 2 brands, 8 active synthetic sample products (plus 2 inactive historical test fixtures), 2 curated collections, and 2 campaign posters. Product prices and stock are illustrative only; all products remain unverified for public search. Use the products, collections, and posters screens to review real API-backed admin data. No demo users or orders were fabricated. The staging store's only enabled payment option is cash on collection with no proof requirement and zero delivery fee. See the [staging catalogue and screenshot evidence guide](https://github.com/kalaabalb/yomart-docs/blob/main/docs/launch/staging-catalog-and-screenshot-evidence.md).

Capture actual screenshots from the running admin at desktop and narrow mobile widths. Include login, dashboard, catalog CRUD, collections/posters, orders, payment settings and responsive navigation. Redact account names, phone numbers, emails, order IDs and any private information. Do not present synthetic sample prices as live offers.
